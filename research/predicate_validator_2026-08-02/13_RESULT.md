X03 and X08 both remain PARTIAL and the reserved pilot remains NO-GO.**

validation happened:

## Why this is not a fake experiment

The replay derives values from hash-pinned CSV summaries generated by earlier
simulator runs. It can test binding, parsing, positive/negative decisions, and
provider-evidence isolation. It cannot establish that the new backend hook ran
inside LIBERO. Every replay row therefore records `test_only=True`,
`live_packet=False`, and `reserved_state_consumed=False`.

The unit producer test uses a fake environment only to prove that the code
calls the two registered task-1 `_eval_predicate` queries. In test mode the
validator advertises `metadata.is_fake=true`; formal readiness cannot accept it.
Production mode advertises non-fake metadata only when test packets are
forbidden and a full source commit is pinned.

The packet hash is an integrity checksum, not a cryptographic signature. Trust
still depends on backend custody and immutable episode artifacts. A learned
provider cannot override a predicate through `provider_evidence`, but a
compromised backend remains outside this adapter's threat model.

## Remaining blockers

1. No live backend packet has been emitted or consumed under the new code.
2. The current main engine initializes one instruction-valued goal; it must be
   replaced or bridged to the atomic semantic slots before this validator can
   guard a real Restore operation.
3. The one-row semantic config is a validated manifest, but the embodied
   six-arm runner does not load it yet.
4. The pinned LIBERO-10 checkpoint is correctly identified, but prior evidence
   shows it fails the replacement updated-goal execution gate. Correct identity
   is not execution competence.
5. Provider, formal atlas/state packet provenance, rollout backend integration,
   and `statsmodels` remain missing.

## Next action

The next useful change is X04 integration, not another offline validator test:
initialize the main comparison from atomic task-1 semantic slots, attach the
snapshot before both provider arms receive the byte-identical RecoveryInput,
and materialize both native FSR and CoPE through the already passing
full-state-v2 boundary. Exercise that path first on states 0--4 or recorded
development packets. Do not inspect state 25/26 until a clean-tree readiness
run observes at least one live production packet and the runner consumes the
semantic config.

Even after that, replacement performance with this OpenVLA checkpoint is not a
good main efficacy test because its updated-goal ceiling already failed.
Cancellation/HALT remains the first embodied mechanism pilot; a replacement
main comparison needs a controller that passes the frozen updated-goal gate.
