# 给 GPU 同事的运行说明

这份文件夹已经包含 r3 的全部实验代码；不需要云端 API。实验固定使用本地
`Qwen/Qwen3-32B`，8 张 RTX 3090 负责 vLLM，LIBERO/MuJoCo 继续用 CPU
OSMesa 和同一套 privileged geometry oracle controller。

## 先不要改实验参数

主配置是 `configs_r3/experiment.json`。固定参数为 20 个 paired seeds、
4096 output tokens、90 秒、temperature 0、三个 profile。任何参数变化都要
另起 protocol version，不能和本轮结果混合。

## 终端 1：启动模型

```bash
cd /path/to/cope_fsrpc_r3_lineage
export COPE_MODEL_PATH=/本机模型绝对路径/Qwen3-32B
export COPE_TENSOR_PARALLEL_SIZE=8
./scripts/serve_qwen3_32b.sh 2>&1 | tee qwen3_32b_server.log
```

如果服务器可以直接访问 Hugging Face，也可不设 `COPE_MODEL_PATH`，脚本会用
`Qwen/Qwen3-32B`。请保留完整 server log。

## 终端 2：运行实验

激活原来能运行 final-v8 LIBERO 的环境，然后：

```bash
cd /path/to/cope_fsrpc_r3_lineage
export MUJOCO_GL=osmesa
export PYTHONPATH="$PWD/code${PYTHONPATH:+:$PYTHONPATH}"
./run_r3_tests.sh
./scripts/run_gpu_fixed_model.sh \
  /绝对路径/cope_fsrpc_r3_qwen32b_run1 \
  2>&1 | tee r3_run1.log
```

脚本会依次执行：模型接口检查、LIBERO 检查、10-seed controller gate、
calibration generation gate、120 个正式 episode、结果完整性校验。任何 gate
失败都会自动停，不要跳过 gate 强行跑。
