## What this resolves

The earlier learned-output bridge stopped before any post-event action. This
result closes that gap for the scoped replacement and cancellation families:
the learned high-level semantic output is not merely scored offline; it changes
the selected physical execution and reaches the modified terminal goal.

## Critical remaining fairness issue

This is an absolute CoPE execution gate, not the final comparative experiment.
The live compact arm still uses the older path contract that previously failed
the shared-envelope fairness audit, and the corrected neutral generic sparse
transaction control is absent from the live embodied runner. Compact and FSR-PC
were semantically invalid on all ten development cases, so executing only CoPE
is correct fail-closed behavior but cannot support a unique-method superiority
claim.

Before spending states 27--46, the live runner must:

1. use the corrected compact semantic interface;
2. add the neutral generic sparse transaction control under the same shared
   envelope;
3. execute every semantically valid arm from a matched replayed physical
   milestone;
4. retain invalid generations as failures without semantic rescue;
5. pass a development-only comparative canary.

uses privileged simulator geometry and is not a learned visuomotor policy.
