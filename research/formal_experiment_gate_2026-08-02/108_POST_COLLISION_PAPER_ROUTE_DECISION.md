# Post-collision paper route decision

Date: 2026-08-04 (Asia/Shanghai)

## Current verdict

**NO-GO for an assurance-architecture novelty claim; HOLD for a narrowly framed
learned-interface/benchmark paper.**

Tang et al. cover the architecture combination that previously looked safest,
while TX-EXEC+ shows that the residual transaction machinery is generically
reproducible.  Current learned and embodied results do not show an advantage
over the strongest neutral sparse control.  Submitting the current package as a
method paper would likely receive a novelty and causal-attribution rejection.

## Fixed hypothesis-compatible repositioning

The project direction remains unchanged: interruption recovery edits persistent
task commitments rather than regenerating actions or replanning the whole task.
The paper question must become narrower:

> Is an occurrence-addressed minimum commitment-update interface a useful
> learned-output factorization for externally authorized, sequential robot goal
> interruptions, relative to capability-matched governed transactions and
> complete state regeneration?

The contribution would be the operational protocol, benchmark and causal
evaluation of that factorization—not the existence of persistent verified
mission state or atomic repair.

## Decisive experiment after the collision

Keep the frozen two-event sequential experiment, but reinterpret it:

1. **Primary:** CoPE minimum typed update versus equally expressive neutral
   JSON-path transaction.
2. **Secondary:** matched complete-state regeneration.
3. **Governance collision control:** a capability-matched typed governed
   proposal using Tang-style affected scope and atomic verification, but without
   CoPE operation names or receipt format.
4. **Unit:** a full dependent two-event sequence, never an event row.
5. **Endpoints:** first-pass semantic validity, no stale execution, preserved
   completed fact, proposal bytes, changed addresses and final intent.

The governance control must pass the same oracle-correct interface gate.  Its
absence would leave the closest published architecture untested.

## Delivery-semantics stress appendix

Add a credential-free adversarial protocol with duplicate, delayed,
out-of-order and conflicting interruption deliveries; lost acknowledgements;
and simulated crash boundaries before validation, after staging and after
publication.  Compare CoPE, generic TX-EXEC+ and the Tang-style governed
proposal carrier under matched validators.

This appendix can establish implementation correctness and failure semantics.
It cannot prove CoPE uniqueness if generic TX-EXEC+ ties—as prior evidence
predicts.  A tie should be reported as a generic transaction result and used to
bound claims.

## Hard submission rules

- If CoPE ties neutral patch again on learned sequence success, do not submit a
  method-superiority paper.
- If CoPE wins only proposal bytes, frame the result as compact specialization,
  not safer or more capable recovery.
- If every governed sparse arm ties, consider a benchmark/protocol paper only
  after adding task diversity and a non-privileged or real-robot execution
  layer.
- A win over the internal FSR-PC arm cannot rescue a neutral/governance tie.
- No “first” claim survives the current audit.

## Minimum evidence for renewed ICRA consideration

1. completed preregistered sequential learned comparison with a positive
   primary CoPE-neutral effect;
2. at least two genuinely different task identities and event schemas;
3. governance-collision control admitted and fairly prompted;
4. one replication model without prompt retuning on formal outcomes;
5. non-privileged execution or a carefully bounded systems/benchmark framing;
6. explicit related-work discussion of Tang et al., InstructFlow, PLanAR and
   generic transaction equivalence.
