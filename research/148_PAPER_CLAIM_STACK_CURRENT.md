# Current CoPE paper claim stack

Date: 2026-08-04

## Submission verdict now

**Weak reject / HOLD.** The architecture-first paper is a NO-GO, and no live
learned occurrence result exists. Code readiness is not scientific evidence.

## Claims already supported

1. Object-derived commitment IDs fail to preserve history when the same
   grounded predicate is authorized as a new temporal occurrence.
2. An occurrence-addressed schema fixes that representational failure, and
   five matched carriers can express the canonical update.
3. Typed operations reduce the tested commission-error surface, while
   independent assurance checks remain necessary for omission completeness.
4. Generic compact transactions can also be sparse, executable, atomic, and
   fail-closed; sparse transactionality is not unique to CoPE.
5. The formal execution/analysis path is zero-retry, crash-safe, and bound from
   durable call intent through response, result journal, and analysis CSV.
6. The task-7 controller does not provide formal recurrence evidence: state 2
   restoration failed and the frozen stop rule prevented suffix selection.

These are mechanism, falsification, and infrastructure findings. They do not
yet constitute a learned robot-recovery method result.

## Closest prior-art boundary

- [Tang et al. (2026)](https://arxiv.org/html/2606.31339) blocks novelty claims
  for a persistent governed mission-state architecture with typed proposals,
  deterministic verification, atomic commit, and completed-work protection.
- [Event Calculus](https://www.sciencedirect.com/science/article/pii/S1574652607030179),
  [commitment lifecycle monitoring](https://link.springer.com/article/10.1007/s10458-012-9202-0),
  and [workflow task-instance logs](https://www.sciencedirect.com/science/article/abs/pii/S0169023X03000661)
  block novelty claims for temporal occurrence identity or event-addressed
  commitment history.
- [PLanAR](https://arxiv.org/html/2602.01662v4) already supplies strong
  multi-task, multi-model, real-robot symbolic verification/replanning evidence
  and sets a much higher external-validity bar.
- [ASPIRE](https://arxiv.org/html/2607.00272) already demonstrates autonomous
  execution-failure diagnosis, repair synthesis/validation, persistent skill
  accumulation, and multi-benchmark long-horizon generalization; CoPE cannot
  claim first agentic robot failure repair or persistent reuse of repairs.

## Only live hypothesis still capable of supporting a method contribution

> Under byte-identical common recovery inputs and strict arm-native output
> contracts, a learned model emits the canonical occurrence-sensitive CoPE
> operation more often and with better locality than both a generic minimum
> JSON-path transaction and a governed affected-scope delta.

This claim is permitted only after the frozen 200-call analysis passes both
co-primary efficacy, safety, and locality gates. FSR-PC or full-replan results
cannot rescue either primary failure.

## Outcome-contingent paper ceiling

| Evidence outcome | Maximum defensible paper direction |
|---|---|
| occurrence neutral/governed failure | stop the CoPE learned-method paper |
| occurrence dual-primary PASS only | symbolic interface/benchmark result; no embodied claim |
| occurrence PASS + task0 embodied failure | benchmark/tool or negative transfer paper at most |
| occurrence PASS + task0 embodied PASS | narrow single-task method candidate; still needs model/task replication for a strong ICRA claim |
| later cross-model and multi-task embodied replication | credible ICRA/CoRL method package, still without architecture-first novelty language |

## Prohibited claims in every outcome of the current runs

- first persistent robot mission-state architecture;
- first local robot repair instead of replanning;
- first occurrence-aware or event-addressed commitment method;
- unique transaction or assurance semantics;
- full replan is intrinsically much larger;
- task-7 physical recurrence success;
- exact symbolic contract conformance proves deployment safety;
- one model and one embodied task establish generality.

## Immediate action

No further offline architecture experiment is decision-relevant. The next
scientific observation must be the separately preregistered one-draw provider
smoke, followed by the frozen occurrence formal if and only if the smoke passes.
The current external blocker is secure credential injection, not missing code,
prompt design, simulator allocation, or statistical specification.
